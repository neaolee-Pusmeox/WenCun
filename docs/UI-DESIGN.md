# 文存界面设计规范

本文记录当前桌面端的视觉语言、组件约定和修改入口。设计从产品本身出发：文存是一间私人档案馆，界面应当像纸、墨与一只钤印，而不是通用后台模板。

## 设计概念

“纸与墨的私人档案馆”。暖纸色承担大面积，墨色负责阅读，松烟绿只做主操作与选中态，封泥红只出现在标识、当前章节编号、待保存状态和极少数需要被看见的小标记上。

- 扁平：没有渐变、玻璃、发光和卡片投影；层次只用 1px 细线、相邻色阶和留白。
- 主窗口的原生标题栏在深色主题下同步为深色；系统不支持时保持默认，不影响内容区。
- 编辑感：页面标题、统计数字和阅读页标题使用宋体，正文与操作使用黑体。
- 安静：导航不使用彩色胶囊或左侧色条；当前项是一层很浅的松烟绿纸色，并把章节编号染成封泥红。
- 有分量：正文为 13–15px，统计为 22px，页面标题为 32px；列表次级信息保留 12px，其余半像素字号不再使用。

## 标识

应用图标把一张暖纸文章收进松烟绿档案盒，封泥红签条略向外偏转，保留原标识的红点记忆。软 3D 只用于应用图标：圆润纸页、宽倒角和左上方柔光提供触感，不增加面部、文字或装饰物。界面与导出页使用同一纸页归档隐喻的扁平标记，不把立体光影扩散到工作区。

| 资产 | 路径 | 用途 |
| --- | --- | --- |
| 图标矢量母版 | `src/WenCun.Desktop/Assets/wencun-icon.svg` | 软 3D 应用图标，640 视图，1024 × 1024 输出 |
| 图标位图 | `src/WenCun.Desktop/Assets/wencun-icon.png` | 512 × 512 可复用位图 |
| 应用图标 | `src/WenCun.Desktop/Assets/wencun.ico` | 可执行文件、窗口、任务栏；16、24、32、48、64、128、256 帧 |
| 扁平标记母版 | `src/WenCun.Desktop/Assets/wencun-mark.svg` | 纸页归档标记，保留纸、盒、红签条 |
| 界面内标记 | `Assets/wencun-mark.xaml` 的 `WenCunMark` | 侧栏品牌区，复用主题语义色 |
| 阅读页标记 | `Core/Export/MarkupWriter.cs` 内联 SVG | HTML 导出与阅读窗口 |

使用规则：

- 标记与“文存”字标并置时，中间留 12px 左右空气；不要在扁平标记外加彩色底、圆环或阴影。
- 浅色主题使用深绿盒体、纸色纸页；深色主题反转为纸色盒体、墨绿纸页。红签条保持不变。
- 图标中没有文字；两条粗纸页笔画只表达文章，不构成字形。16–32px 仍应保留纸页、档案盒、红签条三个识别特征。
- 修改图标时先改 SVG 母版，用 `scripts/render-icon.py` 重新生成多尺寸 ICO 与检查图；同步检查侧栏与阅读页标记，不让三处身份走样。检查图写入 `.tools/logo/soft-3d/`，不入库。

## 字体

| 角色 | 字体栈 | 用法 |
| --- | --- | --- |
| 展示 | `Noto Serif SC`, `Source Han Serif SC`, `STZhongsong`, `SimSun` | 页面标题 32px、品牌字标 18px、统计数字 20–22px |
| 界面 | `HarmonyOS Sans SC`（随程序内置） | 正文/说明 13–14px、文章标题 15px、按钮 13px |
| 等宽 | `Cascadia Mono`, `Consolas` | 文库路径、文章 URL |

界面字体使用 `src/WenCun.Desktop/Assets/Fonts/` 中的 HarmonyOS Sans SC Regular 与 Medium，通过 pack URI 加载，不依赖用户系统安装。它比 Noto Sans SC 在 13px 左右的中文正文更清晰，字面更开阔，标题和按钮也有足够的分量。

展示字体仍使用系统宋体栈，用于 32px 页面标题、20–22px 统计数字和阅读页标题；系统缺少 Noto Serif SC 时回退到思源宋体、华文中宋或宋体。等宽字体只用于路径与 URL，不用于正文。

数字统一使用 tabular figures；标题不追加大写英文、字距或装饰线。

界面字号以整数为主；每个页面以 12、13、15、22px 为主，页面标题额外使用 32px。文字排版统一使用 WPF 的 `Ideal` 模式：在 125% 缩放（120 DPI）下，`Display` 模式会让字形以 96 DPI 的整像素步进后再放大，笔画落点不均匀；`Ideal` 按实际 DPI 使用分数度量，边缘更干净。

浅色主题使用 ClearType 以保留锐度；深色主题自动切换为灰度抗锯齿，避免深底上的彩色次像素毛边。

### 字体许可

HarmonyOS Sans Fonts 由华为设备有限公司以 HarmonyOS Sans Fonts License Agreement 授权，允许在软件中嵌入、捆绑和再分发未修改的字体副本。程序内保留版权声明与完整协议，不修改字形或字体文件。许可原文见 `src/WenCun.Desktop/Assets/Fonts/LICENSE-HarmonyOS-Sans.txt`。

界面侧栏底部保留“字体 HarmonyOS Sans”字样，作为软件内的显著使用声明。

## 版式

- 窗口：1280 × 840 为基准，最小 1000 × 640；侧栏 236px，内容区左右 34px，底部状态栏 32px。
- 侧栏：品牌区、章节导航、当前文库与外观开关。导航行高约 36px，编号 01–03 使用宋体；当前项使用 `NavActiveBrush`，不加大色块。
- 页面标题：32px 宋体，副标题 13px 灰色；标题下 22px 进入工作区。空文库首次启动进入“采集”，已有文库或待保存数据时进入“资料库”，保存成功后进入“资料库”。
- 面板：10px 圆角、1px 边框、无投影；面板内边距 14–20px，列表行以 1px 规则线分隔。
- 底部状态：左侧状态点与当前消息，右侧版本与构建时间；文库路径放在侧栏。长文本截断并提供 Tooltip。

### 三个页面

| 页面 | 结构 | 关键动作 |
| --- | --- | --- |
| 资料库 | 搜索与状态筛选、公众号索引、文章表、分页 | 保存所选、重试失败、重新导出、阅读、打开文件夹 |
| 采集 | 获取目录与状态、文章选择、保存设置 | 获取/停止目录、保存所选、格式与图片规则、更换文库、移除证书 |
| 公众号 | 四个汇总数字、公众号目录行 | 查看文章、待保存、获取目录、重试、重新导出、删除 |

资料库的“待保存”不是独立页面，只是资料库的筛选分支；视觉上沿用同一张表，只替换表头动作。文章行的状态列固定为 96px，操作列固定为 144px；状态标签、导出状态与表头在列内居中，失败行的“阅读”“重试”“文件夹”不改变列宽。

## 组件约定

- 主按钮：深松烟绿（深色主题为纸色），只用于当前视图最重要的动作；同一屏尽量不超过两个。
- 次级按钮：透明底、文字为主；悬停出现浅纸色背景，不使用蓝紫色。
- 危险动作：红色文字按钮；悬停在 `SubtleBrush` 上时仍保持红色。
- 筛选：文字标签 + 当前项 2px 下划线；不使用彩色胶囊。
- 状态：12px 小标签，浅色底 + 同色文字；待保存用封泥红，已保存用松烟绿，失败用朱红。
- 选择：自定义 16px 复选框；选中行使用 `AccentSoftBrush`，勾选标记为纸色。
- 输入：32–34px 高、6px 圆角；聚焦时边框变为 Accent，占位文字使用 Faint。
- 滚动条：10px 透明轨道 + 6px 圆角滑块，无箭头；悬停加深。
- 空状态：保留面板边框，用一句短说明和一个主按钮给出下一步，不放插画或“暂无数据”。
- 焦点：所有可键盘操作控件有可见 Accent 描边；文本输入聚焦时同步改变边框。
- 删除确认与文件夹选择沿用 Windows 系统对话框；本次重构不改确认文案、按钮顺序或危险操作语义。

## 阅读页与导出 HTML

阅读窗口与导出的 HTML 共用 `Core/Export/MarkupWriter.cs` 的样式：

- 纸色背景上放一张 760px 的浅纸阅读面，1px 暖灰边框，无投影。
- 标题使用宋体 34px，正文 16.5px、行高 1.92，最大阅读宽度约 760px。
- 归档提示是暖黄纸条，左侧 2px 封泥红线；引用块也使用封泥红细线。
- 页眉与页脚带小尺寸文存标记；打印时隐藏标识、去掉边框和纸张底色。
- 窄屏去掉纸面边框并缩为 22px 内边距；图片、表格和代码块自适应宽度。

## 动效与响应

- 不加入页面切换动画、悬浮卡片或自动滚动；只保留按钮/列表悬停、进度条和滚动条反馈。
- 采集中的不确定进度使用低透明度脉冲条，不改变布局。
- 资料库与公众号页在最小窗口下仍保持“索引 + 列表”结构；采集页在高度不足时整体滚动，不拆掉保存规则。
- 所有长文本截断处提供 Tooltip；路径使用等宽字体并保留可读前缀。

## 实现入口

| 需要改什么 | 入口 |
| --- | --- |
| 色板 | `Themes/Light.xaml`、`Themes/Dark.xaml` |
| 字体、按钮、筛选、输入、列表、滚动条、焦点 | `Themes/Controls.xaml` |

界面重构以表现层为主；涉及 ViewModel 的改动限于展示属性和只读计数。采集、保存、查询与待保存清单的契约仍由 Core 和既有命令路径负责，不能为了样式方便在 XAML 里直接写业务状态。

## 验证

```powershell
& ./.tools/dotnet/dotnet.exe build WenCun.slnx
& ./.tools/dotnet/dotnet.exe test tests/WenCun.Tests/WenCun.Tests.csproj --no-build
```

原生 UI smoke 使用临时文库，不执行生产 `App.OnStartup`；至少检查资料库、采集、公众号三页的浅色/深色、1280 宽与 1000 宽，以及选中、失败、待保存三种状态。失败与已保存文章必须同屏检查状态标签的横向对齐、行内垂直居中和三个行内操作。构建后确认 `FontFamily.Source` 指向 `pack://application:,,,/WenCun;component/Assets/Fonts/#HarmonyOS Sans SC`，并检查侧栏“字体 HarmonyOS Sans”声明可见。

文字清晰度需在 125% 缩放的 120 DPI 窗口上复核，而不是只在 96 DPI 的离屏截图里看：确认窗口 `VisualTreeHelper.GetDpi().PixelsPerDip` 为 1.25，标题为 15px，`TextFormattingMode` 为 `Ideal`，深色主题下文章标题为浅色（`TextBrush`）且渲染模式为 `Grayscale`。阅读页另用生成的 HTML 在浏览器中检查桌面与窄屏，并检查打印样式。
